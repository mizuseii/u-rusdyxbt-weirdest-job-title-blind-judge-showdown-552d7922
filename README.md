## The title

**Professional Mourner for Strangers' Goldfish** (44 characters)

A professional mourner is a real job. This one grieves, on commission, for goldfish belonging to people he has never met.

## Run

```
python3 main.py
```

Writes the title to `/output/entry.txt` (exactly 44 characters, no trailing newline).
